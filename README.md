# Dual Board Game Console — Sudoku & Tic-Tac-Toe

An **x86 Assembly Language** game project developed for the Computer Organization and Assembly Language (COAL) course at FAST-NUCES. The application combines two classic games—**Sudoku** and **Tic-Tac-Toe**—in a single console-based program.

## Overview

The project demonstrates interactive game logic, input handling, state management, validation, and control flow implemented at the assembly level.

## Games

### Sudoku

- Console-based Sudoku gameplay
- Board and game-state management
- User input and move validation
- Completion handling

### Tic-Tac-Toe

- Two-player console gameplay
- Board state management
- Input validation
- Win and draw detection
- Turn-based game flow

## Technical Concepts

- x86 Assembly Language
- Registers and memory addressing
- Procedures and modular program structure
- Conditional and unconditional branching
- Loops and control flow
- Stack usage
- Console input/output
- Game-state management
- Input validation

## Technology

- **Language:** x86 Assembly
- **Environment:** MASM
- **Library:** Irvine32
- **Course:** Computer Organization and Assembly Language (COAL)
